# photo-to-gouache

> 转水粉绘画风格 — 上传一张照片（风景 / 城市 / 人物均可），一键转成水粉绘本插画风格，同时保留原图的意境与氛围。

## 这是什么
一个 [WorkBuddy](https://www.workbuddy.cn) skill。用户发一张照片，skill 会先让你选输出尺寸、确认后再调用 ImageGen 的图生图能力，把照片转成 **gouache（不透明水粉）绘本插画** 风格。

风格只迁移「画法」（大色块、可见笔触、简化造型、手绘肌理），**不搬运参考图的具体场景元素**，所以无论原图是阳光海滩还是阴雨小巷，都能保住原本的情绪和氛围。

## 特性
- 交互式流程：选尺寸 → 确认 → 生成（不会一上来就出图）
- 4 种尺寸可选：原图比例 / 1:1 / 3:4 / 4:3
- 支持一次发多张图批量处理（串行生成，自动规避文件名冲突与限流）
- 单图约消耗 5–10 credits

## 安装
1. 下载本仓库为 zip，解压得到 `photo-to-gouache/` 文件夹
2. 放入 WorkBuddy 的 skills 目录：`~/.workbuddy/skills/photo-to-gouache/`
3. 在对话中上传照片，说「转插画 / 水粉风 / 绘本风」即可触发

## 风格要点
- 媒介：不透明水粉，大色块 + 可见笔触
- 造型：色块起形、不勾黑边、人物简化为姿态小人
- 色彩：从原图取色再块面化，冷暖对撞，阴影带颜色
- 铁律：只改画法，不改原图的情绪与主题
